# 验证与交付

使用根目录 [README.md](../../../../README.md) 约定的 Go 工具链。在相应包或模块目录内执行 Go 命令，并按本次变更覆盖相关包。

## 查看文档

以下命令从仓库根目录执行；`<包路径>` 与 `<符号>` 替换为目标包与符号：

```bash
# 包摘要、章节和符号
go doc ./<包路径>
go doc ./<包路径> <符号>
go doc ./<包路径> <类型>.<方法>

# 查看包内全部符号的注释
go doc -all ./<包路径>
```

确认标题、列表与代码块对应预期；文档链接的渲染核验方式见 [排版与文档链接](./formatting-and-links.md)。`go doc` 的成功退出证明命令可执行，排版仍需阅读输出核验。

## 检查改动

- 修改 Go 注释、`doc.go` 或示例测试时，对目标文件执行 `gofmt`，并运行静态代码检查与测试（如 `golangci-lint run ./...` 与 `go test -race ./...`）。
- GoDoc 内的代码块和 Markdown 示例属于注释文本；通过对应的示例测试或 `/tmp/` 下的临时测试模块验证其 API 签名、错误处理与确定性输出，结束后清理临时文件。
- 验证代码、测试与工作区完整性时，执行根目录 [AGENTS.md](../../../../AGENTS.md) 要求的构建、测试与格式规范。
- 修改参考规范或其他 Markdown 文档时，执行文档检查：

```bash
markdownlint-cli2 "**/*.md"
git diff --check
```

## 汇报结果

交付时列明实际执行的检查与结果；失败或受阻的检查记录原因，未执行的验证明确说明。
