# 内部符号、并发与测试注释

内部声明按复杂度说明维护者需要掌握的约束：

1. **共享状态**：指出保护状态的锁、允许的并发访问方式和不可变派生关系。
2. **状态变化**：说明启动、停止、缓存、类型锁或延迟重放中不明显的原因。
3. **测试注入**：说明时钟、Reader、Writer 等依赖的默认行为和注入目的。
4. **测试注释**：测试名与测试结构已说明被验证的行为时不加注释；行为边界、输入选择或断言依据从代码中看不出来时再补充说明。

例如，日志派生操作需要保留分组顺序：

```go
// groupOrAttrs 记录一次 WithGroup 或 WithAttrs 派生操作。
// contextHandler 延迟重放这些操作，使每次 Handle 先注入权威根字段，
// 再恢复调用方请求的分组层级。
type groupOrAttrs struct {
	group string
	attrs []slog.Attr
}
```
