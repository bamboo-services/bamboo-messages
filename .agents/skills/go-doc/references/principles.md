# GoDoc 通用原则

本规范依据 GoDoc 最佳实践约定与当前源码工程整理。各主题的阅读入口见 [go-doc Skill](../SKILL.md)。

架构与模块边界由 [AGENTS.md](../../../../AGENTS.md) 和对应工程文档维护；GoDoc 负责代码符号层面的行为契约。示例中的 API 签名和行为需随实现与测试同步核验。

1. **面向调用者**：说明调用方式、输入约束、返回值、错误处理、并发保证与资源归属。
2. **中文与完整句式**：源码注释使用中文，以清晰的肯定句陈述职责、行为边界和约束；符号名称及 `Package` 等 GoDoc 格式标记保留原文。
3. **精准指称符号**：独立符号的声明前文档注释首句以对应标识符开头，使 GoDoc 摘要与声明直接关联。
4. **依据当前行为**：从实现、调用方和测试确认零值、nil、取消、超时、幂等性与并发语义。注释记录长期契约和不明显的原因，实施进度由工程文档承载。
